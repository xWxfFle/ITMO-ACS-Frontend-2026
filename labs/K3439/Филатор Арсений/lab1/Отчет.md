## Задача

Сверстать сайт с входом, личным кабинетом и поиском с фильтрами. Вариант - приложение «Витрина данных».

## Ход работы

Вход. Две колонки: форма и промо-блок. Корень экрана - `main`.

```tsx
export default function SignInPage() {
  return (
    <main className={classes.page}>
      <div className={classes.layout}>
        <SignInForm />
        <SignInIllustration />
      </div>
    </main>
  )
}
```

Вкладки «ЕКП (mosreg.ru)» и «Внешняя УЗ». На первой поле называется «Логин», на второй «Почта». Пока запрос идет, поля закрыты.

```tsx
const activeTab = ldap.value ? 'external' : 'ekp'
const loginLabel = ldap.value ? 'Почта' : 'Логин'

<Tabs value={activeTab} onChange={handleTabChange}>
  <Tabs.List>
    <Tabs.Tab value="ekp">ЕКП (mosreg.ru)</Tabs.Tab>
    <Tabs.Tab value="external">Внешняя УЗ</Tabs.Tab>
  </Tabs.List>
</Tabs>

<TextInput label={loginLabel} error={errorText('email')} disabled={pending} />
<PasswordInput label="Пароль" visible={visible} onVisibilityChange={toggle} disabled={pending} />
<Button type="submit" loading={pending}>Войти</Button>
```

Кабинет показывает имя, должность и организацию. История обновлений открывается модальным окном.

```tsx
<Skeleton visible={!viewer} h={125}>
  <Title order={4}>{viewer?.fullName}</Title>
  <Text>{viewer?.userWork.position}</Text>
  <Text c="dimmed">{viewer?.userWork.companyName}</Text>
</Skeleton>

<Button onClick={open}>История обновлений</Button>

<Modal opened={opened} onClose={close} fullScreen title="История обновлений">
  <Table>
    {changelog.map(({ date, description }) => (
      <Table.Tr key={date}>
        <Table.Td>{date}</Table.Td>
        <Table.Td>{description}</Table.Td>
      </Table.Tr>
    ))}
  </Table>
</Modal>
```

Поиск и реестр наборов сидят в одной оболочке. У поиска три типа сущности.

```tsx
<PageShell title="Поиск">
  <Content />
</PageShell>

const entityOptions = [
  { value: EntityEnum.Category, label: 'Категория' },
  { value: EntityEnum.DataSet, label: 'Набор данных' },
  { value: EntityEnum.Attribute, label: 'Атрибут' },
]
```

Фильтры реестра: статус, информационная система, дерево категорий, поставщик.

```tsx
<Stack className={classes.sidebar}>
  <CheckboxFilterSection title="Статус" options={statusOptions} />
  <CheckboxFilterSection title="Информационная система" searchable multi />
  <DatasetsCategoryFilterTree />
  <CheckboxFilterSection
    title="Поставщик данных"
    searchable={departmentOptions.length > 4}
  />
</Stack>
```

Карточка набора: ошибка, загрузка, затем шапка и панели. Список отчетов собран той же оболочкой.

```tsx
if (datasetError !== null) {
  return <PageShell title="Ошибка"><Text>Произошла ошибка при получении набора данных</Text></PageShell>
}
if (dataset == null) {
  return <PageLoader />
}

<PageShell title="Отчёты" actions={<CreateReportButton />}>
  <Content />
</PageShell>
```

## Вывод

На сайте есть вход с двумя вкладками, кабинет с профилем и модалкой истории, поиск по трем типам сущностей и реестр наборов с фильтрами. Списки и карточки сидят в `PageShell`.
