## Задача

Собрать одностраничное приложение: роутер, запросы к API, деление на компоненты, вынос повторяющегося кода. В курсе пример на Vue. Ниже куски уже собранного SPA на React. Axios не добавлял.

## Ход работы

Роутер собирается из списка маршрутов и истории браузера. В дерево React он попадает через `RouterProvider`.

```ts
export const routes = {
  account: createRoute({ path: '/account' }),
  search: createRoute({ path: '/search' }),
  signIn: createRoute({ path: '/auth/sign-in' }),
  dataSets: createRoute({ path: '/datasets' }),
  datasetView: createRoute({ path: '/dataset/:id<number>' }),
  reportList: createRoute({ path: '/reports' }),
  reportView: createRoute({ path: '/reports/:id<number>' }),
}

export const router = createRouter({
  routes: Object.values(routes),
  controls,
})
```

```tsx
<MantineProvider theme={theme} defaultColorScheme="auto">
  <RouterProvider router={router}>
    <Pages />
  </RouterProvider>
</MantineProvider>
```

Страница входа не импортируется в корне целиком. Роут подгружает ее отдельно.

```ts
export default createLazyRouteView({
  view: async () => import('./page'),
  route: currentRoute,
  fallback: PageLoader,
})
```

Запросы те же, что во второй лабораторной: `createRestQuery` на REST и короткая мутация `UserLogout` на GraphQL. Клиент axios в приложении не подключен.

Экран режется на страницу и куски. `SignInPage` только раскладывает колонки, поля живут в `SignInForm`. Реестр наборов: страница, сайдбар фильтров и лента карточек. Общая рамка - `AppLayout` и `PageShell`.

Повтор страницы лежит рядом с ней: сторы и запрос, компонент читает их через `useUnit`. Где одна модель нужна нескольким блокам, ее достают хуком из контекста.

```ts
export const useSystemViewModel = () => {
  const model = use(SystemViewModelContext)

  if (model == null) {
    throw new Error('SystemViewModelProvider is required')
  }

  return model
}
```

Так же устроены `useSystemsListModel` и `useSystemLogsModel`: хук без провайдера бросает ошибку.

## Вывод

SPA собирается из `RouterProvider`, ленивых страниц и REST-клиента `createRestQuery`. Общая модель нескольких блоков страницы вынесена в хук вокруг контекста.
