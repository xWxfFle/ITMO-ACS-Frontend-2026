## Задача

Разобрать доступность сайта: подписи полей, роли и состояния, которые читает вспомогательная технология.

## Ход работы

Активный пункт меню получает `aria-current`. Пока маршрут не совпал, атрибут не ставится.

```tsx
<Link
  to={to}
  {...props}
  aria-current={active ? 'page' : undefined}
/>
```

Кнопка раскрытия «Мои данные» подписана, у нее есть состояние и тип попапа.

```tsx
<Button
  aria-label="Разделы моих данных"
  aria-expanded={opened}
  aria-haspopup="menu"
  onClick={() => setOpened(value => !value)}
>
  <IconChevronDown size={14} />
</Button>
```

Якорь только для прокрутки закрыт от дерева доступности: `aria-hidden` и `tabIndex={-1}`. У кнопки «Мои информационные системы» тот же набор атрибутов, другая подпись: `aria-label="Мои информационные системы"`.

Поля входа подписаны через `label`. Ошибка висит на том же поле.

```tsx
<TextInput
  label={loginLabel}
  error={errorText('email')}
  disabled={pending}
/>
<PasswordInput
  label="Пароль"
  error={errorText('password')}
  disabled={pending}
/>
<Button type="submit">Войти</Button>
```

Ссылки поддержки - это кнопки-ссылки с видимым текстом и `aria-label` у иконок: «Написать в Telegram», «Написать на почту».

Страница входа обернута в `main`. Кабинет и списки сидят в `PageShell`.

```tsx
<main className={classes.page}>
  <SignInForm />
</main>

<PageShell
  breadcrumbs={[pageBreadcrumbs.home(), { label: 'Поиск' }]}
  title="Поиск"
>
  <Content />
</PageShell>
```

## Вывод

У активных ссылок шапки есть `aria-current`, у меню - имя, состояние и тип попапа. Поля входа подписаны через `label`, ошибка висит на том же поле.
