## Задача

Сделать у сайта светлую и темную тему на CSS-переменных. Схема следует настройке системы, в кабинете есть переключатель.

## Ход работы

Сырые цвета заданы на `:root`. Это числа, не роли кнопок и текста.

```css
:root {
  --primary-500: #897efa;
  --neutral-00: #ffffff;
  --neutral-800: #101828;
  --neutral-900: #030712;
}
```

Роли вешаются на атрибут схемы. Светлая:

```css
:root[data-mantine-color-scheme='light'] {
  --bg-surface-00: #ffffff;
  --text-basic: var(--neutral-800);
  --text-secondary: var(--neutral-400);
}
```

Темная меняет те же имена:

```css
:root[data-mantine-color-scheme='dark'] {
  --bg-surface-00: var(--neutral-800);
  --text-basic: var(--neutral-25);
  --text-secondary: var(--neutral-300);
}
```

Поле читает роль, не hex из палитры.

```css
.input[data-error] {
  color: var(--text-basic);
}
```

Пока пользователь сам не переключил тему, схема берется из системы.

```tsx
<MantineProvider theme={theme} defaultColorScheme="auto">
```

Кнопка в кабинете меняет схему. Подпись зависит от текущей.

```tsx
const { toggleColorScheme, colorScheme } = useMantineColorScheme()

<Button onClick={toggleColorScheme}>
  {colorScheme === 'light' ? 'Темная' : 'Светлая'} тема
</Button>
```

## Вывод

Светлая и темная схемы - два набора одних и тех же переменных. `auto` смотрит на систему, кнопка в профиле переключает схему вручную.
