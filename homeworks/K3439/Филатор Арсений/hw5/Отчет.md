## Задача

Разобрать команды npm и запуск приложения «Витрина данных».

## Ход работы

Скрипты пакета `vitrina-pwa`:

```json
{
  "name": "vitrina-pwa",
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "tsc -b && vitest run && vite build",
    "lint": "eslint",
    "preview": "vite preview --host 0.0.0.0"
  }
}
```

`npm install` ставит зависимости. `npm run dev` поднимает Vite. `npm run build` гоняет проверку типов, тесты и сборку. `npm run preview` отдает уже собранную папку.

Корень экрана. Схема темы по умолчанию смотрит на систему, страницы сидят внутри роутера.

```tsx
export const App = () => {
  return (
    <MantineProvider theme={theme} defaultColorScheme="auto">
      <DatesProvider settings={{ locale: 'ru' }}>
        <RouterProvider router={router}>
          <Pages />
        </RouterProvider>
      </DatesProvider>
    </MantineProvider>
  )
}
```

Два экрана, которые открываются с этого корня.

```tsx
export default function SignInPage() {
  return (
    <main className={classes.page}>
      <SignInForm />
      <SignInIllustration />
    </main>
  )
}
```

```tsx
<PageShell title="Профиль">
  <Title order={4}>{viewer?.fullName}</Title>
  <Text>{viewer?.userWork.position}</Text>
  <Text c="dimmed">{viewer?.userWork.companyName}</Text>
</PageShell>
```

## Вывод

Приложение ставится через `npm install` и поднимается через `npm run dev`. Экран собирается в `App`: провайдер темы, роутер и страницы. Вход и кабинет - отдельные компоненты.
