## Задача

Пройти Flexbox Froggy, Grid Garden и Learn Git Branching (первые 4 урока основ и уроки по удаленным репозиториям). Собрать отчет.

## Ход работы

Flexbox Froggy, русская версия. Лягушек расставлял свойствами контейнера и самих элементов.

По главной оси хватило `justify-content`: `flex-end`, `center`, `space-around`, `space-between`. По поперечной - `align-items`, а одного лягушонка отдельно сдвигал через `align-self`.

Направление ряда менял `flex-direction`: `row-reverse`, `column`, `column-reverse`. Когда лягушка должна была встать не в том месте, куда ее кладет поток, ставил `order`.

Дальше ряд перестал помещаться в одну линию. Включил `flex-wrap: wrap` и выровнял строки через `align-content`. Последние уровни - доли свободного места: `flex-grow`, `flex-shrink`, `flex-basis` и короткая запись `flex`.

Grid Garden. Грядки закрывал линиями сетки, не полями.

Сначала `grid-column` и `grid-row` с номерами линий: от какой до какой занимает вода. Где грядка длинная, писал `span`. Потом задавал саму сетку: `grid-template-columns` и `grid-template-rows`, в том числе через `repeat`. Отдельные клетки менял местами свойством `order`.

Learn Git Branching, вкладка основ, первые четыре урока.

1. Коммит: `git commit`.
2. Ветка: `git branch bugFix`, `git checkout bugFix`, еще один `git commit`.
3. Слияние: вернулся на `main` и сделал `git merge bugFix`.
4. Перебазирование: `git rebase main`, история ветки легла поверх актуального `main`.

Удаленные репозитории на той же площадке.

Клон: `git clone`. У локальной ветки появляется пара на origin, в интерфейсе она помечена как `o/main`. Чужие коммиты без слияния подтягивает `git fetch`. `git pull` делает fetch и сразу сливает их в текущую ветку. Свои коммиты уходят командой `git push`.

Если локальная история и origin разошлись, обычный `git pull` добавляет merge-коммит. Урок про расхождение просит выровнять историю иначе: `git fetch`, `git rebase o/main`, затем `git push`. Когда origin отклоняет push, потому что ветка на сервере ушла вперед, порядок тот же: сначала забрать чужое и перебазировать свои коммиты, и только потом пушить.

## Вывод

Flexbox собирает ряд и колонку, Grid режет область на линии. В Git коммит, ветка, merge и rebase закрывают локальную работу, а fetch, pull и push связывают ее с origin.
