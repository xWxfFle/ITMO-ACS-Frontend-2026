## Задача

Собрать иконки интерфейса в один SVG-спрайт.

## Ход работы

Спрайт лежит в `sprite.svg`. Каждая иконка - это `symbol` со своим `id` и `viewBox="0 0 24 24"`. Снаружи спрайт на страницу не рисуется: его подключают через `use`.

Пять символов: `search`, `user`, `filter`, `moon`, `heart`. Поиск, пользователь и фильтр нарисованы обводкой `stroke="currentColor"`. Луна и сердце залиты `fill="currentColor"`, поэтому цвет берется у родителя, а не зашит в path.

```svg
<symbol id="search" viewBox="0 0 24 24">
  <circle cx="11" cy="11" r="6" fill="none" stroke="currentColor" stroke-width="2"/>
  <path d="M16 16l4 4" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round"/>
</symbol>
```

На странице `index.html` иконка занимает 24 на 24 пикселя. Класс `.icon` задает размер и цвет, сам глиф не дублируется.

```html
<svg class="icon"><use href="sprite.svg#search"></use></svg>
```

В шапке стоят пользователь, поле поиска, фильтр и переключатель темы. На карточке набора сердечко отмечает избранное. Иконка `search` в шапке и в поле берется из одного `symbol`.

```css
.icon {
  width: 24px;
  height: 24px;
  color: #3d4a5c;
}
```

## Вывод

Пять иконок собраны в `sprite.svg`. Страница берет их через `use` и красит через `currentColor`.
